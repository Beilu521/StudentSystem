# 🎓 Student Management System

A simple yet functional Student Management System built with Java, perfect for beginners learning object-oriented programming and basic CRUD operations.

## ✨ Features
- **Add Students** - Input validation for duplicate ID checking
- **Delete Students** - Remove students by ID with error handling
- **Update Students** - Modify name, age, or address of existing students
- **Query Students** - Display all students in a formatted table
- **Menu-Driven Interface** - User-friendly console interface

## 🛠️ Tech Stack
- **Java** - Core programming language
- **ArrayList** - For data storage and management
- **Scanner** - For user input handling
- **OOP Concepts** - Classes, objects, encapsulation

## 🚀 Getting Started
1. Clone the repository
2. Compile the Java files
3. Run `StudentSystem.java`
4. Follow the menu prompts to manage students

## 📁 Project Structure
```

StudentSystem/
├──Student.java          # Student entity class
├──StudentSystem.java    # Main system with CRUD operations

```

## 💡 Learning Outcomes
- Java basics and syntax
- ArrayList manipulation
- Console I/O operations
- Object-oriented design
- CRUD functionality implementation

Perfect for Java beginners to understand fundamental programming concepts! 🌱
